# 比較表・データ表の制作規則

- 複数対象を同じ評価軸で比較する場合や、仕様・長所短所・条件・単位を整理する場合は**表**を検討する。本文で説明したほうがわかりやすい内容を無理に表にしない。
- Markdown pipe table を基本とし、キャプションと `{#tbl-descriptive-name}` を付ける。表番号はQuartoで自動採番し、本文から `@tbl-descriptive-name` でリンク参照する。番号を手入力しない。
- 行と列の意味、前提、単位、数値の出典・比較可能性を明記する。異なる分類軸を混在させない。誤読を招く場合は注記する。
- スマホで列幅を無理に縮小して読めなくしない。狭い画面では表の横スクロールを許可し、見出しの対応を保つ。
- 簡潔な例：

```markdown
@tbl-methods の通り、用途で適した方式は異なる。

| 方式 | 強み | 制約 |
|:--|:--|:--|
| A | 高精度 | 高コスト |
| B | 高速 | 近似誤差 |

: 方式の比較（前提条件を本文に記す） {#tbl-methods}
```

- Quarto外のプレビューでも「表1.1」と番号付きキャプションを表示し、本文参照をクリック可能にする。
