# 作品別 Color Registry：配合の再現と履歴管理

## 目的・保存先

色を日ごとに作り直して混色比が揺れないよう、作品単位で **色ID・四角い表示見本のHEX・具体的な絵具名・混色比**を固定する。
正本はその作品の `color-registry.yaml`。汎用Skillを保管する公開GitHubへ個人の作品データを混入しない。作品Stateの `color_registry.path` で参照する。

## 作業ルール

1. **作品開始時**：`templates/color-registry.yaml` を作品専用の場所に複製。使う絵具のメーカーや画用液をStateに記録。
2. **初回提示時**：台帳を照合し、未登録なら一意の `color_id` を付け、最初に見せた配合（色名・メーカー・量の比・単位）・HEX・部位を保存。初回提案でも `status: proposed` として保管し、保存成功を確認。
3. **再提示時**：色ID・部位・別名で既存色を検索。`active_revision` の配合とHEXをそのまま引用する。丸め・微量の数値化・絵具の無断差替え・再生成は禁止。
4. **変更時**：薄く／赤く等の要望には新リビジョンを *proposed* で追加する。以前の配合を残し、ユーザーが採用したときのみ `active_revision` を更新。すでに塗った部位に合わせるには旧版を参照できるようにする。
5. **不一致・未保存**：過去回答に配合の不一致がある場合は旧記録の出典と実際に使った配合を照合し、勝手に統合しない。台帳が見つからない場合、「同一性未確認」と明示して回復方法を案内する。書込不能なら更新版のファイルを提供する。保存していないのに保存済みと主張しない。

## 色合わせの限界と工夫

- 比率は通常**絵具を出す量の比**。同じメーカー・色名・量の測り方を維持し、試し塗りで既塗装面と比較する。
- 「微量」「ごく少量」は再現誤差が大きいので初出時の表現を維持し、実際の使用量が分かれば実測メモとして追記する。元の混色比を無断修正しない。
- HEXは画面表示の近似色で、絵具の発色、乾燥、照明、写真によって変わる。実物の同一照明下で最終判断する。
- 画用液は色材混合比と別項目で記録。製品名不明のまま具体的な量を断定しない。

## データ形式

`templates/color-registry.yaml` を参照。`colors[].color_id` が固定キー。`revisions[].preview_hex` は表示見本、`revisions[].recipe.ingredients[]` は配合、`active_revision` は採用版。複数のバージョンを残し、出典と初回提示日を記録する。
