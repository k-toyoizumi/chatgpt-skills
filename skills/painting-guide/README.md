# Painting Guide Skill v1.0

初心者の油絵制作を、構想から完成まで支援する日本語Skill。

## 使い方

- Agentに `SKILL.md` を参照させ、描きたい作品の構想や制作写真を共有する。
- 新作は「構想の相談」→「目標画像の生成・選択」→「全体計画の合意」→「STEPごとの制作」→「写真評価・調整」で進める。
- 実制作中は「STEP n の混色と色見本、筆、画用液を教えて」「この写真で次に進める？」などと依頼する。
- Projectでは作品ごとに `references/project-state.md` のテンプレートを複製し、目標画像と進捗写真を別に管理する。

## 設計原則

1. 絵を描く楽しさと本人の創意を尊重。
2. 目標画像の厳密な模写は求めず、最低限の重要要素と難しい部分の簡略化を示す。
3. 四角い実色パッチ・混色比・筆・追加する画用液・塗り方・完了条件を一緒に表示。
4. 乾燥と安全に配慮し、未確認の事実は断定しない。

このフォルダは汎用Skillのみを収録し、作品固有の写真や個人情報は含まない。
